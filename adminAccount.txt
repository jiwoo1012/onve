초기 관리자 계정 생성 기록
작성일: 2026-07-29

- 이메일: qwer@asd.com
- 역할: admin
- 생성 상태: Firebase Console 또는 Firebase Admin SDK에서 생성 대기 (비밀번호 길이 조건 충족)
- 비밀번호: 보안을 위해 이 파일에 기록하지 않음

생성 방법
1. Firebase Console > Authentication > Users에서 이메일/비밀번호 사용자로 위 이메일 계정을 6자 이상의 비밀번호로 생성합니다.
2. 생성된 사용자의 UID를 확인합니다.
3. Firestore Database > Data에서 users/{UID} 문서를 생성하거나 기존 문서를 수정합니다.
4. 문서 필드에는 email, nickname, role: "admin", createdAt을 설정합니다.

주의: 클라이언트 Firestore 규칙은 사용자가 role을 admin으로 직접 생성·수정하는 것을 허용하면 안 됩니다. 초기 관리자 role 지정은 Firebase Console 또는 Firebase Admin SDK로만 수행합니다.
